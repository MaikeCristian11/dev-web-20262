# Etapa 3 — PUT: editar um registro

Suba a API com CORS. Depois `npm install` e `npm run dev`.

O mesmo formulário serve para cadastrar e editar: o que muda é o método e a URL. Clique em Editar em um card e repare no `useEffect` do formulário, que o preenche quando `emEdicao` muda.

Depois de salvar, a lista é atualizada trocando só o item alterado, sem buscar tudo de novo.

Este é um projeto independente; não é necessário copiar os arquivos das outras etapas.
