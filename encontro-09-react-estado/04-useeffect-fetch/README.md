# Etapa 4 — useEffect e fetch: os dados vêm da API

Execute `npm install` e `npm run dev`.

O array de heróis sumiu do arquivo. Os dados chegam da mesma API do encontro 7, pedidos dentro de um `useEffect` com array de dependências vazio.

Sem internet, troque a constante `API` por `'/herois.json'`. A cópia local está na pasta `public` e tem o mesmo formato da API, então nenhuma outra linha muda. As imagens continuam vindo da internet: sem conexão, o card mostra um retângulo cinza e o resto funciona.

Este é um projeto independente; não é necessário copiar os arquivos das outras etapas.
