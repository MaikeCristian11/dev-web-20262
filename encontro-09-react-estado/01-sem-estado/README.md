# Etapa 1 — O problema: a variável muda, a tela não

Execute `npm install` e `npm run dev`.

Abra o console do navegador e digite no campo de busca. O valor aparece a cada tecla, mas a lista de cards não muda. Nada avisou o React de que a tela precisa ser desenhada outra vez.

Este é um projeto independente; não é necessário copiar os arquivos das outras etapas.
