# Etapa 3 — Eventos e estado derivado

Execute `npm install` e `npm run dev`.

Três controles, três estados. A lista visível não é estado: é calculada a cada desenho a partir do que está guardado. Repare também no estado vazio quando os filtros não encontram ninguém.

Este é um projeto independente; não é necessário copiar os arquivos das outras etapas.
